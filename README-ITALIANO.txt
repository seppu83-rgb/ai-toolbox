AI TOOLBOX — PUBBLICAZIONE E APERTURA SU IPHONE

1) Crea un repository GitHub
   - Accedi a https://github.com con il tuo account.
   - Premi New (nuovo repository).
   - Nome: ai-toolbox
   - Seleziona Public.
   - Premi Create repository.

2) Carica i file
   - Nel repository premi Add file > Upload files.
   - Estrai questo ZIP sul computer oppure usa i file contenuti nella cartella.
   - Carica index.html, manifest.webmanifest e sw.js (README facoltativo).
   - Premi Commit changes.

3) Attiva GitHub Pages
   - Apri Settings > Pages.
   - In Build and deployment scegli Deploy from a branch.
   - Branch: main; Folder: /(root).
   - Premi Save.
   - Attendi che GitHub mostri l'indirizzo pubblicato. Di solito:
     https://NOME-UTENTE.github.io/ai-toolbox/

4) Apri su iPhone
   - Apri l'indirizzo GitHub Pages in Safari.
   - Premi Condividi (quadrato con freccia).
   - Scegli Aggiungi alla schermata Home > Aggiungi.

NOTE
- Non inserire password, token o codici GitHub in chat.
- L'app è una web app: i link agli strumenti richiedono Internet.
- Preferiti salvati sul dispositivo/browser tramite localStorage.
- I servizi AI elencati possono avere requisiti hardware, limiti o costi; controlla le condizioni ufficiali.
